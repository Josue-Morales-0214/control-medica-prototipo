# 📱 Control Médica — Frontend PWA

Aplicación cliente construida con **React 19**, **Vite** y **TailwindCSS**, configurada como Progressive Web App (PWA) con almacenamiento local offline en Cloud Firestore.

## 🚀 Comandos de Desarrollo

* `npm run dev` — Inicia el servidor de desarrollo local con Vite.
* `npm run build:staging` — Compila la aplicación utilizando variables de `.env.staging`.
* `npm run build:production` — Compila la versión de producción optimizada para despliegue.
* `npm run preview` — Previsualiza localmente el paquete de producción generado en `dist/`.

## 📦 Configuración de Entorno
Copia `.env.example` hacia `.env.local` y configura las credenciales públicas de Firebase Web SDK.
